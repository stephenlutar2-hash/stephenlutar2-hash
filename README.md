## The claim discipline

| State | Meaning |
|---|---|
| **LOCKED-PROVEN** | Machine-checked in the cited proof artifact |
| **EVIDENCE-BACKED** | Supported by a named source, runtime observation, or receipt |
| **CONJECTURE** | Open mathematical or engineering claim; not presented as proven |
| **UNAVAILABLE** | The required evidence or runtime capability is not currently present |

The unconditional uniqueness claim for **Λ** remains a conjecture; a conditional form is proved under stated assumptions. A receipt proves the bound record and verification path—not every property of the underlying computation. No ATO or FedRAMP authorization is claimed.
