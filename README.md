## How I label claims

| State | Interpretation |
|---|---|
| **LOCKED-PROVEN** | Machine-checked in the cited proof artifact |
| **EVIDENCE-BACKED** | Supported by a named source, observation, or receipt |
| **CONJECTURE** | Open mathematical or engineering claim; never presented as proven |
| **UNAVAILABLE** | Required evidence or runtime capability is not currently present |

The unconditional uniqueness claim for **Λ** remains a conjecture; only a conditional result is proved under stated assumptions. A receipt proves its bound record and verification path, not every property of the underlying computation. No ATO or FedRAMP authorization is claimed.
